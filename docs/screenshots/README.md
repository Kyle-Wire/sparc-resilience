# Screenshots

Place your SPARC screenshots in this directory using the following naming convention:

| Filename | Content |
|----------|---------|
| `01-project-setup.png` | Project setup and template selection |
| `02-data-upload.png` | Data upload and preview |
| `03-dag-builder.png` | Visual causal DAG editor |
| `04-physics-config.png` | Physics constraints and priors |
| `05-pipeline-running.png` | Pipeline execution with live progress |
| `06-results-maps.png` | Spatial results and model diagnostics |
| `07-scenario-tables.png` | Intervention scenario comparison |
| `08-uncertainty.png` | Monte Carlo uncertainty bands |
| `desktop-01.png` | Desktop app main view |
| `desktop-02.png` | Desktop app spatial map |
| `video-thumbnail.png` | Thumbnail for the demo video |

Recommended dimensions: **1280×800** or **1920×1080** for consistency.
