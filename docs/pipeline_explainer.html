SPARC Pipeline

A geospatially-aware, physics-constrained machine learning pipeline for resilience analysis. SPARC combines classical geographically-weighted models, differentiable neural surrogates, and Bayesian causal inference to produce credible, physics-consistent predictions and actionable intervention recommendations.

ℹ

Domain Coverage: Urban heat islands, wildfire risk, groundwater, coastal flooding, air quality, stormwater, noise, seismic, drought, and more — via configurable domain templates.

Stage 0 — Correlogram Analysis

Module: sparc.run.correlogram_analysis

Before any model is fit, SPARC characterizes the spatial dependence structure of the data. This stage answers: how far does spatial correlation extend, and is it directionally symmetric? Every bandwidth and kernel shape used in later stages is derived here — not guessed.

Matérn Covariance Model

The spatial covariance between locations $s_i$ and $s_j$ is modeled as:

Matérn Covariance
$$C(h; \kappa, \nu) = \sigma^2 \frac{2^{1-\nu}}{\Gamma(\nu)} \left(\sqrt{2\nu} \, \kappa \, h\right)^\nu K_\nu\!\left(\sqrt{2\nu} \, \kappa \, h\right)$$

where $h = \|s_i - s_j\|$, $\kappa$ = decay rate (1/length), $\nu \in \{0.5, 1.5, 2.5\}$ = smoothness, $K_\nu$ = modified Bessel function. $\nu = 0.5$ gives exponential decay; $\nu = 2.5$ gives twice-differentiable fields.

KernelField

The primary output is a KernelField — a per-predictor record holding: isotropic $\kappa$ and $\nu$; anisotropic $\kappa_x$, $\kappa_y$, $\theta$, eccentricity; per-pair bandwidth-to-outcome; and $\kappa$ posterior samples. Every downstream model reads from this structure rather than using fixed hardcoded bandwidths.

✓

Key insight: Block sizes derived from the target correlogram prevent spatial leakage in cross-validation — a common pitfall when applying standard k-fold CV to spatial data.

Stage 1 — GWEN Variable Selection

Module: sparc.run.gwen_variable_selection  ·  Optional

Geographically Weighted Elastic Net — identifies predictors that matter spatially across the study area. Unlike global variable selection, GWEN asks whether each predictor is selected at each location.

Algorithm

  1. Sample up to 5,000 locations across the study area
  2. At each location, weight neighboring observations by adaptive spatial kernel (k-NN, default $k=500$)
  3. Fit a local ElasticNetCV on the kernel-weighted sample
  4. Record which variables were selected (non-zero coefficient)
  5. Compute per-variable selection frequency = fraction of locations where variable was selected

Stage 2 — Spatial Cross-Validation & Neural Meta-Learner

Modules: sparc.run.enhanced_spatial_cv · sparc.run.v2_neural_training

The core modeling stage. Four classical geographically-weighted models are trained under spatially-buffered cross-validation. Each is mirrored by a differentiable PyTorch surrogate. A physics-informed meta-learner fuses all surrogates and is trained with a 10-term staged PDE loss.

2a. Spatial Cross-Validation Strategy

Standard $k$-fold CV would produce overoptimistic estimates for spatial data because nearby observations in training and test sets share spatial autocorrelation. SPARC uses buffered spatial block CV:

📐

Block size = zero-crossing of target correlogram (from Stage 0). A buffer zone equal to one block size surrounds each test block and is excluded from training — preventing leakage of spatially correlated information. Default: 5 folds, parallelized via ProcessPoolExecutor.

Physics Encoder Detail

The PDEInformedPhysicsEncoder decomposes the temperature field into two physically meaningful parts:

Physics Field Decomposition
$$T(s) = w(s) \cdot T_p(s) + (1 - w(s)) \cdot T_h(s)$$

$T_p(s)$ = particular solution — GELU MLP driven by forcing proxies (albedo, impervious fraction, anthropogenic heat)
$T_h(s)$ = homogeneous solution — SIREN network on coordinates; naturally satisfies $\nabla^2 T_h = 0$
$w(s)$ = learned blend weight balancing source-driven vs. harmonic contribution

3a. MC³ — Bayesian DAG Structure Learning

When data-driven structure learning is enabled, SPARC runs Metropolis-Coupled MCMC (MC³) over the space of DAG structures using parallel tempering.

BGe Score — Bayesian Gaussian Equivalent
$$\text{score}(G, D) = \log p(D \mid G) = \sum_{j=1}^{p} \log p(X_j \mid \text{PA}_j^G)$$

Each term computed from Wishart–Beta conjugate prior. Sufficient statistics $(\mathbf{S}, \bar{x})$ are precomputed for $O(m^2)$ lookup per edge subset — score-cached by sorted column tuple.

n_chains4Parallel chains at temperatures [1.0, 0.75, 0.55, 0.40]
n_iterations50,000Maximum; early-stops when edge-prob Δ < 0.5% over 2,000-step window

3b. Double Machine Learning (DML) — Structural Coefficients

For each edge in the DAG, SPARC uses DML to obtain doubly-robust causal coefficient estimates that are consistent even if one nuisance model is misspecified.

DML Cross-Fitted Residualization
$$\tilde{Y}_i = Y_i - \hat{E}[Y \mid Z_i], \quad \tilde{T}_i = T_i - \hat{E}[T \mid Z_i]$$ $$\hat{\beta}_{DML} = \arg\min_\beta \sum_i (\tilde{Y}_i - \beta \tilde{T}_i)^2$$

Nuisance models $\hat{E}[\cdot]$ are HGB or OLS, cross-fitted on $K$ folds (optionally spatial folds). Residuals are orthogonal to confounders, eliminating confounding bias.

Shrinkage Toward Physics Prior
$$\hat{\beta}_{\text{final}} = (1 - \lambda_s)\,\hat{\beta}_{DML} + \lambda_s\,\beta_{\text{prior}}, \quad \lambda_s \approx 0.25$$

Adaptive shrinkage based on prior confidence. Clamped within ±50% of prior. Sign consistency enforced via monotone constraints.

3c. NUTS — Bayesian Edge Posteriors

Per-edge Bayesian GLMs sampled with No-U-Turn Sampler (NUTS) via numpyro. Priors are informed by Stage 2 GWR $\beta$ posteriors from the Bayesian MGWR ensemble.

Per-Edge Bayesian GLM
$$Y \sim \mathcal{N}(\beta T + X\gamma,\; \sigma^2)$$ $$\beta \sim \mathcal{N}(\mu_{\text{GWR}},\; \sigma_{\text{GWR}}^2) \quad \text{(informed by Stage 2 β posterior)}$$

4,000 samples + 1,000 warmup · 2 chains · target accept rate 0.90. Full posterior draws stored for direct sampling in Stages 4+.

3d. Spatial CATE — Heterogeneous Treatment Effects

CausalForestDML (EconML) estimates per-location heterogeneous treatment effects, using spatial coordinates + Laplacian eigenmaps + confounders as effect modifiers.

🔷

Phase 7 Anisotropic Warp: When a KernelField is available, spatial coordinates are warped into the treatment variable's anisotropic principal frame before feeding the causal forest — so forest neighborhoods respect the corrected length scales.

3e. Causal Dose-Response Curves

Bayesian dose-response curves $\tau(t) = \mathbb{E}[Y(\text{do}(T=t))] - \mathbb{E}[Y(\text{do}(T=t_0))]$ are computed per-cell with 89% HDI credible bands. Saturation is detected at the first dose where marginal slope drops below 50% of peak slope.

Budget-Constrained Allocation

SPARC solves a budget-constrained allocation problem for urban planning use cases:

Optimization Problem
$$\max_{x} \sum_i b_i \cdot x_i \quad \text{s.t.} \quad \sum_i c_i \cdot x_i \leq B, \quad 0 \leq x_i \leq x_{\max}$$

$b_i$ = per-cell benefit (NUTS slope or $\alpha$ field) · $c_i$ = per-cell cost · $B$ = total budget

SolverComplexityUsed when
Greedy$O(n \log n)$$n \leq 50{,}000$: sort by $b_i/c_i$, fill to budget
Greedy + 2-opt$O(n^2 \log n)$$n \in (50\text{k}, 250\text{k}]$: greedy + pairwise swap refinement
MILP (PuLP/CBC)Exact$n \leq 5{,}000$: binary treat/don't-treat decisions
📊

Pareto Frontier: Evaluates at budget multipliers {0.5×, 0.75×, 1.0×, 1.25×, 1.5×} — reporting total benefit and Gini coefficient (equity proxy) at each level. Gini ≈ 0 = evenly spread; Gini ≈ 1 = concentrated.

Model Architecture — Deep Dive

Geographically Weighted Models

The classical models all share the same principle: instead of fitting a single global relationship $Y = X\beta + \epsilon$, fit a separate local model at each observation point $s_i$, weighting nearby observations by a spatial kernel.

Geographically Weighted Regression (GWR)
$$\hat{Y}(s_i) = \mathbf{x}(s_i)^T \hat{\beta}(s_i), \quad \hat{\beta}(s_i) = (X^T W(s_i) X)^{-1} X^T W(s_i) y$$ $$W(s_i) = \text{diag}\left[K\!\left(\frac{d(s_i, s_j)}{h_i}\right)\right]_j$$

$h_i$ = adaptive bandwidth (from Stage 0 KernelField); $K$ = kernel function (Gaussian, exponential, or bisquare). GWR produces a spatially-varying coefficient surface $\beta(s)$ — a map of how each predictor's relationship with the outcome varies across the study area.

Differentiable Surrogates

Each classical model has a PyTorch twin that can participate in end-to-end gradient-based training:

SIREN Physics Encoder

Standard MLPs with ReLU activations produce poor derivatives — important when enforcing PDE residuals. SPARC uses SIREN (Sinusoidal Representation Network) for the harmonic solution $T_h$:

SIREN Activation
$$\phi_i(x) = \sin(W_i x + b_i), \quad \frac{\partial^2 T_h}{\partial x^2} = -\omega^2 T_h$$

The sinusoidal activation means gradients are analytically meaningful — SIREN naturally satisfies $\nabla^2 T_h = 0$ on uniform coordinate inputs, making it ideal for the homogeneous part of the heat equation.

Sparse Spatial Attention

SparseSpatialAttention (O(N·k))
$$\text{Attn}(s_i) = \text{softmax}\left(\frac{Q(s_i) K(s_j)^T}{\sqrt{d}} \cdot \mathbf{1}_{j \in \text{kNN}(i)}\right) V(s_j)$$

Attention is restricted to the $k$-nearest spatial neighbors of each point — $O(N \cdot k_{\text{nn}})$ instead of $O(N^2)$. Distance scale $\sigma$ is a learnable parameter initialized from Stage 0 bandwidth, making the attention head interpretable as a per-cell spatial influence surface.

Loss Functions — Deep Dive

The meta-learner is trained with a 10-term staged-curriculum PDE loss plus 4 additional regularization terms — a total of up to 14 objectives, progressively activated to avoid destabilizing a partially-converged network.

Joint Loss Function
$$\mathcal{L} = \lambda_{\text{MSE}} L_{\text{MSE}} + \lambda_{\text{CE}} L_{\text{CE}} + \lambda_{\text{phys}} L_{\text{phys}} + \lambda_{\text{smooth}} L_{\text{smooth}} + \lambda_{\alpha_s} L_{\alpha_s} + \lambda_{\text{prior}} L_{\text{prior}} + \lambda_n L_n + \lambda_{\text{PDE}} L_{\text{PDE}}$$

Core Loss Terms

1

MSE — Data Fidelity

$$L_{\text{MSE}} = \frac{1}{N}\sum_i (T_{\text{pred}}(i) - y_i)^2$$

Standard supervised regression loss. Anchors the network to match observed temperatures.

2

Cross-Entropy — Exceedance Calibration

$$L_{\text{CE}} = -\frac{1}{NK}\sum_i\sum_k \left[\mathbf{1}(y_i > \tau_k)\log p_k(i) + \mathbf{1}(y_i \leq \tau_k)\log(1 - p_k(i))\right]$$

Calibrates the exceedance probability heads $p_k(i) = \sigma(\text{head}_k(i))$ for threshold $\tau_k$. Critical for risk quantification (e.g., P(temp > 35°C)).

3

Physics Residual — Steady-State Heat Equation

$$L_{\text{phys}} = \frac{1}{M}\sum_{i \in \text{valid}} \left(\frac{\alpha(i)\,\nabla^2 T(i) - S(i)}{\sigma_{\text{res}}}\right)^2$$ $$\nabla^2 T(i) \approx \frac{T_N + T_S + T_E + T_W - 4T(i)}{h^2}$$

Enforces the steady-state heat equation $\alpha \nabla^2 T = S$. $\alpha(i)$ = learned diffusivity field; $S(i)$ = observed source term. Normalized by running std $\sigma_{\text{res}}$ to keep scale at $O(1)$.

4

Alpha Smoothness — Spatial Regularization of $\alpha(x)$

$$L_{\alpha_s} = \lambda_L \cdot \boldsymbol{\alpha}^T L_{\text{graph}}\, \boldsymbol{\alpha}$$

$L_{\text{graph}}$ = spatial graph Laplacian from $k$-NN ($k=50$). Encourages the learned diffusivity field to vary smoothly across space — a natural prior for physical processes.

5

Alpha Prior Regularization

$$L_{\text{prior}} = \frac{1}{N}\sum_i \frac{(\alpha(i) - \alpha_{\text{prior}}(i))^2}{\sigma_{\text{prior}}(i)^2}$$

Weight decays with curriculum: $w(t) = w_0 \cdot (0.1 + 0.9 \exp(-0.05(t - 30)))$. Prevents $\alpha$ from drifting far from physics-informed expectations early in training, then relaxes to allow data-driven learning.

6

Neighbor Consistency

$$L_n = \frac{1}{N}\sum_i \sum_{j \in \mathcal{N}(i)} \text{softmax}(\alpha(i))_j \cdot (T_{\text{pred}}(i) - T_{\text{pred}}(j))^2$$

Spatially-aware smoothness — nearby predictions should agree, weighted by the learned $\alpha$ field. Complements the physics residual by enforcing local consistency.

10-Term PDE Curriculum Loss

The PDELoss module adds 10 physics terms that activate progressively during training to avoid instability:

Epoch 0

Term 1 — Heat Diffusion

$\alpha \nabla^2 T - S \approx 0$ — steady-state heat equation

Epoch 5

Term 2 — Energy Balance

$Q^* - Q_H - Q_E \approx 0$ — net radiation minus sensible and latent heat fluxes

Epoch 10

Terms 3–4 — Directional Consistency & Anisotropy Alignment

Penalize inconsistent directional curvatures; penalize spurious isotropy where Stage 0 data shows anisotropy

Epoch 15

Terms 5–8 — Gradient-Flux, Gaussian Curvature, Alpha Smoothness, Alpha Prior

Fourier's law flux consistency; Hessian regularization; spatial smoothness of $\alpha(s)$; deviation from mixture-model prior

Epoch 20 (multi-snapshot only)

Terms 9–10 — Transient Consistency & Nocturnal Cooling

$\partial T / \partial t$ consistency across time snapshots; radiative-cooling boundary condition at night

Curriculum Ramp Weight
$$w_k(t) = \begin{cases} 0 & t < t_k \\ (t - t_k)\,/\,5 & t_k \leq t < t_k + 5 \\ 1 & t \geq t_k + 5 \end{cases}$$

Each newly activated term ramps linearly over 5 epochs — preventing gradient shocks to a partially converged network.

Causal Framework — Deep Dive

SPARC's causal framework is designed around two core questions: (1) do the data support the assumed causal structure? and (2) what is the effect of intervening on a treatment variable?

Identification Strategy — Pearl's Do-Calculus

For each treatment-outcome pair, SPARC computes the backdoor adjustment set $Z$ — the minimal set of confounders that, when conditioned on, blocks all backdoor paths from treatment to outcome:

Backdoor Adjustment (Pearl 2009)
$$\mathbb{E}[Y \mid \text{do}(T = t)] = \int \mathbb{E}[Y \mid T = t, Z = z]\, p(z)\, dz$$

This quantity equals the observational conditional expectation after adjusting for all backdoor paths — without requiring a randomized experiment.

Multi-Method Synthesis

SPARC triangulates causal estimates across methods to assess robustness:

Classical

GWR β Posterior

Spatially-varying regression coefficients from Bayesian MGWR ensemble. Local but assumes linearity.

Semi-Param

DML Residualized

Doubly-robust cross-fitted estimator. Global but flexible nuisance models.

Bayesian

NUTS Posterior

Full posterior over causal coefficient; priors from GWR. Propagates uncertainty to Stage 4.

Non-Param

Spatial CATE

Per-location heterogeneous effects via causal forest. Captures effect modification by location.

✓

Uncertainty Propagation: NUTS posterior draws are stored and sampled directly in Stage 4 scenario simulation — so scenario confidence intervals inherit the full causal uncertainty from Stage 3.
