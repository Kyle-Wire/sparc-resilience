## Implementation Note — S3-11: Empirical Cholesky mass matrix for NUTS

- **Files changed:** `sparc/causal/nuts.py` (~50 lines across 7 functions), `sparc/run/v2_bayesian_causal.py` (~14 lines)
- **What was done:** Added `mass_chol: torch.Tensor | None = None` parameter to all six NUTS internals (`_kinetic_energy`, `_leapfrog`, `_find_reasonable_epsilon`, `_dual_average_step_size`, `_nuts_step`, `_build_tree`) and to the public `run_nuts()` API (`mass_matrix_chol` kwarg). When provided, momentum is sampled as `r = L @ randn()`, kinetic energy is computed via `solve_triangular(L, r)`, and the leapfrog position step uses `cholesky_solve(r, L)`. The warmup diagonal estimation is skipped when a Cholesky is supplied. In `_run_nuts_sampling()`, a block-diagonal empirical Cholesky is computed from `X_standardized.T @ X_standardized / n` (beta block) padded with identity for the sigma2 block, then passed as `mass_matrix_chol=mass_L` to `run_nuts()`.
- **Tests:** 15/15 passed (`test_nuts_per_edge` 5/5, `test_causal_stack` 10/10); run time 10.4 s.
- **What was learned:** Threading `mass_chol` as an explicit keyword argument through the call chain is straightforward because all functions already accepted `inv_mass_diag` the same way. The diagonal warmup block needed only a single `if mass_chol is None:` guard to remain fully backward-compatible. The full-dim Cholesky needs to cover sigma2 (last dim) too, so a block-diagonal construction with a 1.0 sigma2 entry was necessary rather than the bare `X^T X` matrix.
