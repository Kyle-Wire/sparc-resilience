## Grounded Directions

### 1. Full Cholesky Mass Matrix in NUTS Leapfrog (S3-11 complete)
**Gap:** `sparc/causal/nuts.py` — `run_nuts()` now accepts `mass_matrix_chol` but uses diagonal approximation `diag(M⁻¹)`. The correlation structure of the predictor covariance is discarded. `_leapfrog` position step still uses element-wise `inv_mass_diag * r`; the correct step for full Cholesky is `L⁻ᵀ L⁻¹ r`.

**Roadmap reference:** Phase 5 — Causal Inference Leadership (sampling efficiency)

**Academic method:** Riemannian MALA / Riemannian Manifold HMC (Girolami & Calderhead 2011, JRSS-B). The Cholesky mass matrix IS RMHMC with a constant (non-position-dependent) metric tensor — the simplest Riemannian geometry case.

**Minimal implementation:**
```python
# Add _MassMatrix class (~25 lines) to nuts.py:
class _MassMatrix:
    def __init__(self, chol_L=None, inv_diag=None):
        self.L = chol_L
        if chol_L is not None:
            self.L_inv = torch.linalg.inv(chol_L)
        self.inv_diag = inv_diag
    def sample_momentum(self, shape, dtype, device):
        xi = torch.randn(shape, dtype=dtype, device=device)
        return (self.L @ xi) if self.L is not None else (xi * (1/self.inv_diag).sqrt() if self.inv_diag is not None else xi)
    def kinetic(self, r):
        if self.L is not None:
            z = self.L_inv @ r; return 0.5 * float((z*z).sum())
        if self.inv_diag is not None: return 0.5 * float((r*r*self.inv_diag).sum())
        return 0.5 * float(r @ r)
    def M_inv_r(self, r):
        if self.L is not None: return self.L_inv.T @ (self.L_inv @ r)
        if self.inv_diag is not None: return self.inv_diag * r
        return r
# Replace inv_mass_diag parameter with mass: _MassMatrix in _leapfrog, _kinetic_energy,
# _nuts_step, _dual_average_step_size, _find_reasonable_epsilon, _compute_hamiltonian.
# Change leapfrog position step: theta += step_size * mass.M_inv_r(r)
```
5–6 functions touched, all within `nuts.py`. Complexity: medium.

## Blue-Sky Ideas

### A. Normalizing Flows Over DAG Posterior (DiBS → Flow)
**Adjacent field:** Variational inference with normalizing flows (Rezende & Mohamed 2015; Neural ODE flows, Chen et al. 2018 NeurIPS)

**Connection to SPARC:** DiBS already does particle-based variational inference over the continuous Z-space (Z_k = soft adjacency matrix). The natural extension is a **continuous normalizing flow** (CNF) that learns p(Z | D, physics) directly — instead of K fixed particles, a flow-based distribution over Z-matrices. This would give:
1. Direct density estimation of the DAG posterior (not just point mass particles)
2. Richer exploration through ODE-parameterized flow trajectories
3. Exact log-likelihood of any candidate DAG under the posterior

**SPARC infrastructure:** `sparc/causal/dibs.py` is the natural base. The SVGD update is already a Stein variational approximation to the posterior; replacing it with a CNF's adjoint ODE step is a principled upgrade.

**Potential payoff:** Publishable result on continuous DAG posterior estimation with physics constraints. Connects to the DiBS paper (Lorch et al. 2021) follow-up line.

---

### B. Spatial Causal Confounder Detection via Latent Sheaf Diffusion
**Adjacent field:** Sheaf neural networks (Bodnar et al. 2022, NeurIPS) × spatial causal inference

**Connection to SPARC:** Latent spatial confounders (e.g., wind patterns, urban morphology factors not in the DAG) manifest as spatially smooth residual fields — i.e., fields with low sheaf coboundary energy. A sheaf diffusion layer over the KNN graph could learn to extract these latent confounders from model residuals and feed them back as additional DAG nodes, iteratively deconfounding the causal graph.

**SPARC infrastructure:** `sparc/physics/pde_operators.py` has `_build_cardinal_neighbors()` — the natural sheaf base space. `sparc/causal/sensitivity.py` already computes E-values for unobserved confounders — this would give the confounders an explicit spatial representation rather than a scalar sensitivity bound.

**Potential payoff:** New capability: spatially-explicit confounder recovery. Directly addresses the "spatial confounders" weakness in all existing spatial causal inference methods.
