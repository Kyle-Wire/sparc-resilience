## Grounded Directions

### Direction 1 — Surrogate Gate-Weight Feedback (Candidate A) — COMPLETED
**Gap:** `SpatialGatingHead` stored `_last_gate_weights` (detached) but these were never connected to the surrogate training signal. All surrogates received the same `lambda_base * MSE` gradient regardless of how much the meta-learner relied on them.
**Roadmap ref:** Phase 1.1 (SPARC_Future_Roadmap.md) — "End-to-end gradient flow through surrogate ensemble"
**Method:** EMA buffer over gate weights (decay=0.99). Surrogate fidelity weight for surrogate k = `(1 − ema_gate_k).clamp(min=0.1)`. Surrogates with low gate weight get higher fidelity pressure — they need to track their V1 targets more closely to remain useful ensemble members.
**Implementation:** `_gate_ema` buffer in `_exec_cv_fold`; `surr_fidelity_weights` param in `sparc_joint_loss()`

### Direction 2 — Replay Interface Depth (Candidate B) — COMPLETED
**Gap:** `compute_replay_loss()` blocked: caller must provide `base_preds` from old-city surrogates not available at new-city training time. `CoresetSelector` imported but never instantiated in `_exec_cv_fold`.
**Roadmap ref:** Phase 1.1 — "Experience replay on coreset data from previous cities"
**Method:** `CityReplayState` dataclass captures full forward-pass tensors at coreset-selection time. `compute_replay_loss_from_state()` uses current-city surrogates to produce `base_preds` for old-city feature distributions (intentional: the meta-learner should output correct targets regardless of which surrogate predictions it receives). Pre-computed per fold before the epoch loop to avoid per-batch overhead.
**Implementation:** `sparc/training/replay.py` + `_replay_states` pre-computation in `_exec_cv_fold` + `total_loss += _replay_lambda * compute_replay_loss_from_state(model, rs)` alongside EWC

### Direction 3 — ProcessRateNet Alpha-Physics Curriculum (Candidate C) — COMPLETED
**Gap:** ProcessRateNet pre-trains to land-cover class centroids via MSE, then this scaffold is dropped abruptly. During Stage B physics ramp, alpha can drift away from the class-centroid prior before the physics loss has enough signal to constrain it.
**Roadmap ref:** Phase 1.2 — "Physics-constrained process rate"
**Method:** Keep the class-centroid scaffold active throughout training but decay it inversely to the physics ramp: full scaffold pressure in Stage A, decay 1.0→0.1 across Stage B ramp, minimal (0.1×) in Stage C. This creates a soft transition: physics takes over as the scaffold releases.
**Implementation:** `"alpha_class"` term in `sparc_joint_loss()` + `get_lambda_schedule()` + `"alpha_class": 0.05` in `target_lambdas`

### Direction 4 — Bilevel Meta-Gradient Lambda Optimizer (Candidate D) — COMPLETED
**Gap:** CMA-ES finds lambda values once before training, gradient-free, then freezes them. During training, the loss landscape shifts as the model learns — but the lambdas cannot adapt.
**Roadmap ref:** Phase 1.3 (SPARC_Future_Roadmap.md) — "Adaptive loss balancing"
**Method:** First-order DARTS approximation (no `retain_graph=True`). `LambdaOptimizer` uses softplus-constrained parameters, Adam outer optimizer (lr=1e-3). Fires every 5 epochs in Stage C only (not during curriculum ramp) to avoid interfering with the physics activation schedule. Uses a held-out mini-batch (512 points) from the training set as the validation signal.
**Implementation:** `sparc/training/meta_lambda.py` (new) + wiring in `_exec_cv_fold`

### Direction 5 — FoldTrainer Testability Seams (Candidate E) — COMPLETED (facade)
**Gap:** `_exec_cv_fold` is ~1500 lines with no internal seams. Gradient pathways cannot be tested independently. Architecture changes cannot be verified without running a full fold.
**Roadmap ref:** Phase 0 code quality (SPARC_Integration_Status.md) — "Testability"
**Method:** `FoldTrainer` class in new file `sparc/run/fold_trainer.py`. Provides `build_models()` (primary seam — tests model architecture), `pretrain_surrogates()`, `pretrain_process_rate()`, `predict_oof()`, and `run()` (delegates to `_exec_cv_fold`). Zero regression risk — `_exec_cv_fold` unchanged.
**Implementation:** `sparc/run/fold_trainer.py` (new)

## Blue-Sky Ideas

### Idea 1 — Sheaf-Diffusion Loss for Scale-Free Spatial Consistency
**Source field:** Topological signal processing (Bodnar et al. 2022, *CW-Networks*)
**SPARC connection:** The cardinal-neighbor graph built in `_build_cardinal_neighbors()` is a natural 1-complex (edges between N/S/E/W neighbors). A cellular sheaf assigns a vector space (the local prediction field) to each node and edge, with restriction maps that encode the expected relationship between adjacent nodes' predictions. The sheaf coboundary operator generalizes the graph Laplacian and provides a MAUP-resistant consistency condition.
**Potential payoff:** Formal MAUP robustness proof (publishable result), multi-scale consistency guarantee
**Existing infrastructure:** `_build_cardinal_neighbors`, `sparc/physics/pde_operators.py`, existing `sheaf_delta` param in `sparc_joint_loss()`
**Note:** The `sheaf_delta` parameter in `sparc_joint_loss()` already anticipates this — the infrastructure seam exists.

### Idea 2 — Implicit Neural Coreset Selection (K-Medoids → Energy-Based)
**Source field:** Energy-based models / Langevin dynamics (Du & Mordatch 2019; Grathwohl et al. 2020)
**SPARC connection:** `CoresetSelector` currently uses greedy K-medoids — a gradient-free O(N·k) algorithm. An energy-based coreset selector would define `E(z) = −‖model(z) − y‖` as the selection energy and use Langevin sampling to find points that maximally stress the current model. This yields coresets weighted toward the model's current failure modes rather than the feature space centroid — a smarter anti-forgetting signal.
**Potential payoff:** Dramatically better coreset quality for replay, especially in OOD regions where forgetting is worst
**Existing infrastructure:** `sparc/training/replay.py` (`CoresetSelector`), trained `model` available after each fold
