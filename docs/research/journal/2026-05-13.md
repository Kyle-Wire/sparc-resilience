### 1. Minimum Effective Range (MER) Block Size from Stage 0 `effective_range_matrix`
**Gap:** `EnhancedSpatialCV.get_block_size_from_config()` reads the Stage 0 `optimal_block_size` scalar, but ignores the `effective_range_matrix` which encodes per-variable-pair spatial ranges from the Matérn fit. The standalone `spatial_kfold_enhanced()` function falls back to `estimate_spatial_autocorrelation_range(coords, y)`, requiring labeled data. A self-supervised block size should use the minimum effective range across all predictor pairs — this is the tightest spatial autocorrelation constraint and requires zero labels.

**Roadmap ref:** Stage 0 → Stage 2 circular loop (themes.md); Phase 3 prerequisite (zero-shot operation without ground labels).

**Method:** Valavi et al. (2019) "blockCV: Spatial blocking for cross-validation to evaluate spatial predictions" — block size should equal or exceed the spatial autocorrelation range of the response OR the predictors. Stein (1999) — intrinsic correlation function: the minimum effective range across variables is the most conservative block size needed to decorrelate any variable pair.

**Implementation sketch:**

### 2. OOF Spatial Intelligence Extraction → JEPA Pretraining Seed
**Gap:** `EXTRACT_OOF_INTELLIGENCE = False` in `enhanced_spatial_cv.py` line 118. The flag is wired — `train_single_model_fold_worker()` calls `extract_from_fitted_model(...)` when the flag is True, but `oof_extraction_hooks.py` does not exist. GWR's spatially-varying local coefficients (β-maps: one vector per location per fold) and GWRF's spatial Gini importances are computed during each fold but **silently discarded**. These are self-supervised spatial embeddings: they encode *how the spatial process varies across the domain* without using the label value per se — only the spatial structure of model fit.

**Roadmap ref:** Phase 1.3 (JEPA pretraining, completed 2026-05-12). The current JEPA pretrain uses random feature masking; seeding it with GWR β-map patterns from Stage 2 would give the trunk a richer spatial prior before supervised training.

**Method:** Spatial eigenvector maps (Griffith 2003); GWR local coefficient maps as spatial bases (Fotheringham et al. 2002). Treat the stack of GWR local β-coefficients as a spatial representation — the JEPA trunk should predict β-map structure in masked geographic regions from unmasked context. This is label-free because β-maps are a property of the spatial covariance structure, not the label magnitude.

### 3. Spatial MAE Pretext on Feature Matrix before CV Loop
**Gap:** The 4 base models (OLS, GWR, GWRF, GAM) start supervised training from scratch at every fold. There is no self-supervised warm-start that exploits the spatial structure of the feature matrix X (not requiring y). The `spatial_patch_mask()` function in `jepa_loss.py` exists and is tested — it builds geographic disk masks. It is only called from within `v2_neural_training.py`, not from `enhanced_spatial_cv.py`.

**Roadmap ref:** Phase 1.3 (JEPA pretraining) — a parallel version applied to the sklearn-style base models.

**Method:** Masked Autoencoder (He et al. 2022, MAE); I-JEPA (Assran et al. 2023). Mask a geographic patch of the feature matrix (20–40% of points). Train a shallow MLP or linear decoder to reconstruct masked feature values from unmasked context, using spatial coordinates as positional embedding. The learned encoder is then used to compute the `physics_feats_extended` tensor for the neural meta-learner (Stage 2 → Stage 2 loop). The base models themselves (GWR, GWRF) are unchanged; only the physics feature tensor fed to the meta-learner is improved.

**Implementation sketch:**
```python
# In v2_neural_training.py, before CV loop (in addition to existing JEPA pretrain phase):
def _run_spatial_mae_pretext(physics_feats, coords, device, n_epochs=20, mask_ratio=0.35):
    """Label-free spatial MAE on feature matrix — warm-starts physics representation."""
    from sparc.training.jepa_loss import spatial_patch_mask
    encoder = nn.Sequential(
        nn.Linear(physics_feats.shape[1], 64), nn.SiLU(),
        nn.Linear(64, 32),
    )
    decoder = nn.Linear(32, physics_feats.shape[1])
    opt = torch.optim.AdamW(list(encoder.parameters()) + list(decoder.parameters()), lr=3e-4)
    for epoch in range(n_epochs):
        mask = spatial_patch_mask(coords, mask_ratio=mask_ratio, n_patches=4)
        context = physics_feats[~mask]
        target = physics_feats[mask]
        # Mean-pool context → latent → decode
        z_ctx = encoder(context).mean(0, keepdim=True).expand(mask.sum(), -1)
        loss = F.mse_loss(decoder(z_ctx), target)
        opt.zero_grad(); loss.backward(); opt.step()
    # Return encoder weights for physics_feats pre-projection
    return encoder

# Gate: config["jepa"]["spatial_mae"] = true/false (new config key)
```

### 4. JEPA Trunk Latent Geometry for Fold Representativeness (Area of Applicability)
**Gap:** `spatial_kfold_enhanced()` assigns folds based purely on geographic blocking or K-means on coordinates. It does not verify that each fold is representative in the *feature space*. A geographically separated test fold that is feature-similar to training produces optimistically biased OOF scores; a geographically close but feature-diverse fold produces pessimistically biased scores. The JEPA pretrain trunk (now available after Phase 1.3) produces 32-dim latent embeddings of every point — these are a richer representativeness criterion than coordinates alone.

**Roadmap ref:** Phase 4 (zero-shot generalization): "the model predicts spatial structure relative to the thermal anchor." A fold that is far from the train set in latent space is a proxy for a zero-shot unseen region.

**Method:** Meyer et al. (2021) "Predicting into unknown space? Estimating the area of applicability of spatial prediction models" — the NNCV dissimilarity index D_i = min(d(x_i, X_train)) / mean(d(X_train, X_train)) marks test points that are OOD from training. Apply this to JEPA latent embeddings: fold assignment is valid only when D_i < threshold for the majority of test points.

**Implementation sketch:**
```python
# New function in enhanced_spatial_cv.py:
def latent_guided_spatial_kfold(
    X, coords, n_splits=5, block_size=None, buffer_size=0,
    trunk_checkpoint_path=None,
) -> list[tuple[np.ndarray, np.ndarray]]:
    """Spatial CV folds guided by JEPA trunk latent-space representativeness."""
    folds = spatial_kfold_enhanced(X, np.zeros(len(X)), coords, n_splits, block_size, buffer_size)
    if trunk_checkpoint_path is None:
        return folds  # degrade gracefully to geographic-only
    from sparc.models.neural_meta import SPARCMetaLearner
    trunk = _load_trunk(trunk_checkpoint_path)
    trunk.eval()
    with torch.no_grad():
        latents = trunk.encode_physics(torch.tensor(X).float()).numpy()  # (N, 32)
    refined = []
    for train_idx, test_idx in folds:
        d_train = pairwise_distances(latents[train_idx]).mean()
        d_test_to_train = pairwise_distances(latents[test_idx], latents[train_idx]).min(axis=1)
        aoa_mask = d_test_to_train / d_train < 1.5  # inside area of applicability
        if aoa_mask.mean() > 0.7:
            refined.append((train_idx, test_idx))
        else:
            # Fold is OOD — log warning, still include but flag
            print(f"WARNING: fold has {(~aoa_mask).mean()*100:.0f}% OOD test points (AoA threshold)")
            refined.append((train_idx, test_idx))
    return refined
```

### 5. Spatial Consistency as Self-Supervised Hyperparameter Criterion
**Gap:** GWR bandwidth, GWRF k-neighbors, and GAM spline count are currently optimized by minimizing labeled OOF RMSE. The `calculate_fold_spatial_autocorr()` function in `enhanced_spatial_cv.py` already computes Moran's I on residuals — but this is diagnostic-only. Making it the *primary* optimization criterion in self-supervised mode (when `y` is not available or should not be used for hyperparameter selection) would enable fully label-free model selection.

**Roadmap ref:** Phase 3 prerequisite (zero-shot mode). When satellite inputs are available but no ground truth exists (Phase 3.1 satellite ingestion), the model must select hyperparameters without labels.

**Method:** Burrough & McDonnell (1998) — spatial smoothness as model quality criterion; Liu et al. (2016) — Kernel Stein Discrepancy (KSD) as label-free model quality; Moran's I on model residuals as a spatial consistency score: a good spatial model should have near-zero residual autocorrelation.

**Implementation sketch:**
```python
# In generate_optimized_oof_predictions() or a new _self_supervised_hparam_tune():
def score_model_spatial_consistency(model, X_train, X_test, coords_train, coords_test) -> float:
    """Label-free spatial consistency score: lower Moran's I on leave-one-out residuals = better."""
    # Use LOOCV on a small spatial sample (200 points) to get residuals without labels
    from sklearn.neighbors import NearestNeighbors
    # For each test point, predict from its k-nearest train neighbors
    # Residual = prediction_at_location - prediction_smoothed_over_neighbors
    # Moran's I on these residuals → score
    pred = model.predict(X_test, coords_test) if 'coords' in ... else model.predict(X_test)
    spatial_residuals = pred - _spatial_smooth(pred, coords_test, bandwidth=500)
    return calculate_fold_spatial_autocorr(spatial_residuals, coords_test)
```

## Blue-Sky Ideas

### A. Spatial Contrastive Learning for Cross-City CV Block Invariance
**Source field:** Instance discrimination contrastive learning (SimCLR — Chen et al. 2020) × spatial geostatistics

**Core idea:** In multi-city settings, two geographic blocks with similar land cover (e.g., dense urban core in Providence and Boston) should be close in the model's representation space; blocks with dissimilar land cover should be far apart — even across cities. A spatial contrastive loss `L_NCE(z_block_A, z_block_B, negative_blocks)` trains a block encoder that is *content-invariant to geography but sensitive to process type*. Applied as a self-supervised pretext in Stage 2, this would produce base model initializations that generalize across cities by construction — without any label alignment.

**Relevant SPARC modules:** `CityRegistry` coresets (400-point representative samples per city), `KernelField` (defines "spatially similar"), `sparc/training/jepa_loss.py` (JEPA loss infrastructure), `sparc/run/enhanced_spatial_cv.py` (fold generator).

**Potential payoff:** Cross-city CV folds that test genuine geographic generalization (not just physical separation); enables the scenario where Stage 2 in Boston is warm-started from Providence's block representations. Directly feeds Phase 2 (Central Registry) — city block contrastive loss becomes the alignment mechanism in the federated registry.

**SPARC infrastructure:** The K-medoids coreset already selects 400 representative points per city. Positive pairs = two coreset blocks with similar KernelField bandwidth; negative pairs = blocks from different bandwidth clusters. The contrastive encoder shares the JEPA trunk.

### B. Variational Spatial Block Autoencoder (VSBA) for Label-Free Fold Quality
**Source field:** Variational Autoencoder (Kingma & Welling 2013) × GP spatial priors (Matérn) × self-supervised CV calibration

**Core idea:** A VAE with a Matérn GP prior on the latent space — trained on the *feature distribution* of each CV block — learns a posterior distribution over spatial fields. The ELBO of the VAE evaluated on a test block, conditioned on the training blocks' posterior, provides a label-free quality score: "how likely is this test block's feature distribution under the spatial field model learned from training?" High ELBO = the test block is in-distribution from the training field; low ELBO = the test block is OOD. This gives Stage 2 an honest generalization score without needing labeled ground truth — the spatial structure is the signal.

**Relevant SPARC modules:** `ProcessRateNet` (α(x) field — already a spatially-varying latent), `SparseSpatialAttention` + `EMATrunk` (architecture components for the encoder), `sparc/physics/pde_operators.py` (Laplacian prior on latent space). The ELBO would include the Stage 0 Matérn kernel as the GP prior, coupling the self-supervised fold quality score to the same spatial covariance structure as the correlogram.

**Potential payoff:** A calibrated label-free CV score that adapts to the spatial covariance of the domain — cities with high spatial autocorrelation get conservative (high-ELBO-threshold) fold scores; cities with low autocorrelation get permissive scores. Makes the "proportion of useful CV folds" depend on the physics of the domain, not just geography.
